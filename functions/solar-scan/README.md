# WattBund Solar-Scan Function

Die Function lädt pro Scan-Kachel ein bayerisches DOP20-Luftbild, lässt installierte
PV- und Solarthermieflächen durch `qwen3.8-max` erkennen und sendet ausschließlich
Geometrie und Schätzwerte an die WattBund-Anwendung zurück. Luftbilder werden nicht
gespeichert. Jeder Fund bleibt bis zur manuellen Admin-Prüfung unveröffentlicht.
